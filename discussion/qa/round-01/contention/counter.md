## 쟁점별 응답

### R1 [수용] — 헤드라인 KPI가 우리 조건에서 시연 0건 → 정합성 깨짐

red 맞다. 현 context는 `캐시 우회 순수 추론 pass^k(k=5) ≥70%`를 **주 KPI(헤드라인·PoC 대상)**로 올렸는데(§측정 line 27·29), 같은 pass^k 실측을 feasibility-filter는 **[발표 서사](실측 불가)**로 분류했다(_feasibility-filter QA-09 행·line 90). 발표의 *대표 숫자*가 "존재하지 않는 시스템에서만 나오는 값"이라는 자기모순이 맞다. PoC로 실제 시연되는 것은 "캐시 우회 *방법론 모델* + 캐시 On이 치트임을 대조"뿐이고(§검증 전략 line 57: "캐시 On(~100%)이 치트임을 **대조 시연**"), 순수 추론 pass^k 절대값 자체는 끝내 미측정이다.

**핵심 진단**: 헤드라인을 *값(70%)*에 걸어서 깨졌다. 우리 조건에서 시연 가능한 것은 **"값"이 아니라 "방법론(대조)"** 이다. 그러니 헤드라인을 **시연 가능한 명제**로 옮긴다.

→ 권고 델타 (기존 → 새 제안):
- **기존**: 주 KPI(헤드라인·PoC 대상) = `순수 추론 재현율(캐시 제외) ≥70% (pass^k, k=5)`.
- **새 제안**: 주 KPI(헤드라인·PoC 대상) = **`캐시 On/Off 일관성 갭 (Δ = pass^k_cacheOn − pass^k_cacheBypass)`** — *방법론 모델*에서 캐시 On은 ~100%, 캐시 우회는 그보다 낮게 나옴을 **대조로 시연**하는 것. 헤드라인 명제 = **"캐시는 일관성을 입증하지 못한다(Δ가 크다 = 캐시가 일관성을 가린다)"**. 이건 시연 0건이 아니라 우리가 만드는 *방법론 모델 자체가 시연*이다.
  - `pass^k 70%·k=5`는 **헤드라인에서 강등** → 보조 KPI(가드레일·예시 합격선)로 내린다. "값은 실환경 측정으로 확정" 꼬리말 유지.

**분산 ≤0.2의 정규화 척도 정의** (red가 R1에 함께 물음 — line 22·27 "0.2가 무엇의 0.2인지 불명"):
- **정의**: 재실행 N회의 결정 결과를 **유한 라벨 집합 C**(노드 판단의 가능한 분류 — 예: {승인, 반려, 보류, …})로 매핑한 뒤, **정규화 엔트로피(normalized Shannon entropy)** 로 흩어짐을 잰다.
  - `H_norm = − Σ_{c∈C} p_c · log p_c / log|C|` (p_c = N회 중 라벨 c 빈도, |C|≥2).
  - 범위 = **[0,1]**: 0 = N회 전부 한 라벨(완전 일관) · 1 = |C|개 라벨에 균등 분산(최대 흔들림). |C|로 나눠 라벨 수에 무관하게 정규화 → "0.2"가 라벨 개수와 무관한 절대 비교값이 됨.
  - 합격선 `≤0.2` = "재실행이 한 라벨에 충분히 몰려 있다"는 뜻(엔트로피 상위 20% 이내 흩어짐 금지). **자유형 텍스트 출력이면 라벨 매핑(클러스터링/판정 게이트)이 선행**해야 함을 silent cap에 명시 — 이 매핑 게이트는 R2의 대리 게이트와 동일 컴포넌트로 재사용한다.

### R2 [부분수용] — 유효-결정률의 앵커(NQA-B)가 [생략]이라 ②가 placeholder

red의 진단("NQA-B가 [생략]이면 ②는 값을 낼 경로가 없는 교차 의존, '일관+정확 닫힘'이 서류상으로만 성립")은 **맞다**. 현 context line 31·58은 ②를 "NQA-B golden 연계"로만 닫았는데, golden set 구축은 _feasibility-filter에서 [생략](line 35·42·73)이라 산출 경로가 실제로 부재하다. 여기까진 수용.

**다만 red의 선택지 (a)"②를 NQA-B 의존 open-issue로 강등" 단독은 과소 처방이다.** 강등만 하면 원 렌즈2 지적(정확성 앵커 부재)이 "한 칸 미뤄졌을 뿐"이라는 red 자신의 비판이 그대로 남는다. 그래서 red의 (b)를 채택 — **golden 없이도 산출 가능한 대리 유효성 판정**을 ②의 *1차 게이트*로 도입하고, golden은 *2차(정밀)*로 분리한다. 이게 부분수용 지점이다.

→ 권고 델타 (기존 → 새 제안):
- **기존**: `유효-결정률 ≥95%` — "재실행 N회 중 정책상 유효한 결정 비율(**NQA-B golden 연계**)".
- **새 제안**: ②를 **2단 게이트**로 분리 정의 —
  - **②-1 대리 유효-결정률 (golden 불요, 우리 조건에서 산출 가능)** = 재실행 결과가 **정책 룰셋/제약 위반 검사**(C-제약 위반, allowlist 위반, 스키마/구조 위반, 명백한 정합성 위반 = "hard-invalid")를 통과하는 비율. golden 정답이 없어도 **"명백히 무효인 결정"은 룰로 걸러낼 수 있다**(필요조건 게이트). 이건 우리 방법론 모델에서 룰 체커로 시연 가능 → **[발표 서사]가 아니라 [반영] 가능**.
  - **②-2 정밀 유효-결정률 (NQA-B golden 의존)** = golden 대비 *정답성*까지 본 유효 비율. **NQA-B 미구축 → open-issue로 명시 강등**, "NQA-B와 짝지어야 닫힘"을 교차 의존으로 남김(현 line 80 유지하되 "②=닫힘"이 아니라 "②-2=NQA-B 의존 open"으로 정직하게 표기).
- **효과**: "일관+정확"의 *정확* 절반 중 **"명백한 무효 차단"은 지금 닫고**, "정답성"만 NQA-B로 미룬다. red가 우려한 "서류상 닫힘"을 ②-1로 실질화하고, 못 닫는 ②-2는 placeholder가 아니라 *선언된 open-issue*로 전환(차이: placeholder는 숨은 빈틈, open-issue는 추적되는 빈틈).

### R3 [수용] — importance 상향 여지와 R1·R2의 순서 충돌

red 맞다. R1(헤드라인 측정 불가)·R2(앵커 미구축)가 미해결인 채 importance만 L→상향하면 "발표 비중 큰데 핵심 KPI는 시연·산출 불가"인 QA가 상위로 오는 모순이다. 상향은 *결과*여야지 *전제*면 안 된다.

→ 권고 델타 (기존 → 새 제안):
- **기존**: line 81 "importance 상향 여지 — NQA-B와 묶이면 상향 검토(사람 결정)".
- **새 제안**: **상향을 R1·R2 해소에 게이트로 묶는다.** context의 importance 메모와 open-issue에 다음 선결 조건을 명시 —
  - "importance 상향(L→M 검토)은 **(i) 헤드라인이 시연 가능한 명제(캐시 On/Off Δ)로 재정의되고 (ii) ②-1 대리 게이트가 정의되어 ②가 추적되는 open-issue가 된 뒤** 사람이 결정한다. 두 선결 조건 미충족 시 L 유지."
- 근거: 우선순위(=발표 비중)는 "이 QA가 측정 가능한 형태로 정돈되었는가"에 종속되어야 한다. 측정 불가 상태의 상향은 발표에서 약점만 키운다(R1의 "헤드라인 = 시연 불가"가 상위 슬라이드로 노출).

## 최종 권고 델타 (Applier 반영용 — 원 counsel/현 context 대비)

> 우선순위: 아래 델타 > 원 counsel(최신 권고 우선). Applier는 이걸 *다음 라운드/수정 거리*로 반영(backtest — 현 반영을 되돌리진 않음).

1. **헤드라인 교체 (R1)**: 주 KPI(PoC 대상)를 `pass^k ≥70% 값` → **`캐시 On/Off 일관성 갭 Δ`의 대조 시연**으로. 헤드라인 명제 = "캐시는 일관성을 입증하지 못한다". `pass^k 70%·k=5`는 보조 KPI(예시 합격선)로 강등.
2. **분산 척도 정의 (R1)**: `재실행 분산 ≤0.2` = **정규화 Shannon 엔트로피 H_norm ∈[0,1]** (라벨 집합 C 매핑 후, `−Σp·log p / log|C|`). 자유형 출력은 라벨 매핑 게이트 선행을 silent cap에 명시.
3. **②를 2단 분리 (R2)**: ② `유효-결정률 ≥95% (NQA-B 연계)` → **②-1 대리 유효-결정률**(정책 룰셋/제약 위반 검사 통과율, golden 불요·[반영] 가능) + **②-2 정밀 유효-결정률**(NQA-B golden 의존, **open-issue로 명시 강등**). "②=닫힘" 표현을 "②-2=NQA-B 의존 open"으로 정직화.
4. **importance 게이트 (R3)**: 상향 검토를 위 1·3 해소를 **선결 조건**으로 묶어 context importance 메모/open-issue에 기입. 미충족 시 L 유지.
5. (부수) open-issue 트래커에 "QA-09 ②-2 ↔ NQA-B golden 교차 의존"을 등록(현 QA-07 first-pass 게이트 의존과 동일 구조로 묶음).
