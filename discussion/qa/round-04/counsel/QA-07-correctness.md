## Reviewer 지적 요약
★★★ 만점 캡(92~98%)+κ 조건은 "100%=난이도 부족" 통찰 정식화 모범. red-team: (1) **★★☆ (90,92) 2%p 좁음 + (98,100) 무등급 공백**(권고 1·Med), (2) **judge κ는 도메인 의존** — 인용 κ(o4-mini 0.873 등)는 일반 벤치라 quantize 도메인과 apples 아님(권고 2·Med·C1), (3) **main 축(golden 정답률)이 [발표 서사]라 실측 불가** → 모델 추정 별점·순환(권고 3·Med·C3), (4) QAS-07 참조 추가(권고 4·Low).

## 개선안 (정의·KPI 기존→제안)

### (A) ★★☆ 대역 확장 + (98,100) 공백 정리 (권고 1)
- **★ 급간 기존 → 제안**:
  - 기존: `★★★ 92~98% / ★★☆ 90~92% / ★☆☆ ≥90% / 불합격 <90% 또는 100% 또는 κ미검증`.
  - 제안: **`★★★ 92~99% / ★★☆ 90~93% / ★☆☆ ≥90% / 불합격 <90% 또는 =100% 또는 κ미검증`**. ★★★ 상한을 99%로 넓혀 (98,100) 공백 제거(100%만 불합격=난이도 부족 신호 유지), ★★☆를 [90,93)으로 확장해 2%p→3%p 변별 여유. 단조성 유지(★☆☆ 진입 90%·★★☆ 90~93·★★★ 93~99).
  - 주의: ★☆☆ ≥90%와 ★★☆ [90,93) 경계 표기는 `★☆☆ [90,91) / ★★☆ [91,93) / ★★★ [93,99] / 100%=불합격`으로 명시(≥/> 모호 제거 — QA-04와 동형 처리).

### (B) judge κ 도메인 재측정 명시 (권고 2·C1)
- **조건 기존 → 제안**: `judge κ≥0.8 선검증` → `judge κ≥0.8 선검증 — **κ는 우리 단계별 quantize golden으로 재측정(일반 벤치 κ 복제 아님)**. 인용 κ(일반 QA frontier judge)는 도메인 특화 정답성 판정에서 더 낮을 수 있음(silent cap)`.

### (C) rework율 보조 별점 축 (C3 — main 축 실측불가 보강)
- **기존**: golden 정답률이 유일 main 별점 축([발표 서사]).
- **제안**: **rework율(자동 산출물이 후속 단계/재시도로 되돌아오는 비율)을 보조 별점 축 병기** — rework는 golden 없이도 파이프라인 로그에서 산출 가능. 보조 ★: `rework율 ≤5% = ★★★ / 5~15% = ★★☆ / 15~30% = ★☆☆`. ATAM 비교 시 정답률이 미실측이면 rework율로 변별("모델 추정 + 실측 가능" 이중 축, QA-11 ②-1과 동형).
- silent cap: golden·judge 미구축으로 정답률 main 축은 모델 추정. judge κ도 golden 의존이라 순환(정답률←golden←judge κ←인간라벨←미수행) 명시.

## 근거 (레퍼런스 + 검증 결과)

**C4 — judge κ 인용**: o4-mini 0.873 등 일반 벤치 LLM-as-judge κ는 본 검증에서 1차 대조 미완 → "확인 불가, 도메인 재측정 필요"로 명시(수치 복제 아님). golden dataset + LLM-as-judge 다수결(인간 일치 75~90%)은 필드 표준([LLM-as-judge](https://www.comet.com/site/blog/llm-as-a-judge/) · Council.md §4 정확성). 100% 통과=난이도 부족 신호도 표준(MMLU 90%+ 변별력 상실).

## PoC 증명법

### PoC-07: golden 정답률 + rework율 이중 축 (eval 하네스 아키타입)
- 가설: "golden 정답률은 모델 추정이나 rework율은 실측되어 보조 별점 축이 된다."
- 지표: golden 정답률(judge 채점, 인간 라벨 대조 κ), rework율(파이프라인 로그). 합격선: ★ 경계 변별 + κ ≥0.8.

- 절차: ① judge κ 선검증(인간 라벨 대조). ② golden fan-out 채점. ③ rework율 로그 집계. ④ 난이도 자동 flag(정답률 100%면 부족).

- 리스크/한계(silent cap): golden·인간 라벨 미구축이면 정답률·κ는 [발표 서사]. judge 비결정·비용도 관리 대상.
