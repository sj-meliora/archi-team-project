## 2. C1~C4 PoC 대응 요약

- **C1 apples-to-apples**: PoC-06(직접 vs 간접 injection 차단율 차이 실증)이 대표. 나머지(QA-01/05/07/08/09/13)는 silent cap 명문화 + 우리 조건 재측정 단서로 응답(전 PoC가 "인용 = 다른 셋업, 우리 PoC로 확정" log).
- **C2 margin 규칙화**: QA-06 단일 Y=5%p / QA-01 "천장 거리 비례 차등" / QA-08 "tail+폭주 흡수 5%" / QA-10 "compute critical path 하한 2h" / QA-13 "분포 두께 차등" — 경계별 margin에 **근거 부여**. PoC가 천장 위치를 측정해 margin 검증.
- **C3 보조 별점 축(이중 축)**: QA-11 ②-1 / QA-07 rework율 / QA-13 재시도 오버헤드 / QA-12 prompt·tool 수정 수 — main 축이 [발표 서사]면 실측 가능 보조 축으로 ATAM 변별력 보강. PoC-11B·07·13·12가 보조 축 산출 증명.
- **C4 출처 신뢰성**: 웹 검증 완료(§3). 잔여 미대조 인용은 "확인 불가"로 정직 표기.
