격리 경계 4단 스펙트럼 — 벽의 재질이 결정을 가른다

컨테이너(커널 공유)와 VM(커널 통째) 사이에는 두 개의 중간 지대가 있다. gVisor는 컨테이너 쪽에서 출발해 공유 커널로 가는 문을 좁혔고, microVM은 VM 쪽에서 출발해 하드웨어 벽만 남기고 짐을 뜯어냈다. 양극단은 기준선으로 격하되고, 결선은 이 중간 둘이다.

벽 = SW 규칙 · 기동 가벼움 · 탈출 쉬움 격리 강도 · 기동/밀도 비용 → 벽 = 하드웨어 · 기동 무거움 · 탈출 어려움

결선(gVisor vs microVM)을 가르는 두 질문 실측 의존 — 구조는 고정, 수치는 측정으로

Q1

인프라 게이트

클러스터가 bare-metal 또는 nested virtualization을 지원하는가? 지원하지 않으면 microVM 계열은 원천 탈락 — 결선에 gVisor만 남는다.

Q2

성능 게이트

dp2가 확정한 20 GB 중간 산출물의 로컬 볼륨 I/O에서 gVisor의 가로채기 세금이 E2E budget(QA-10 ≤ 5%)을 잠식하는가? 잠식하면 microVM 우위.

기동·오버헤드 수치는 대표 공개값 기반 예시(Firecracker ~125 ms/~5 MB, gVisor 아키텍처, Kata Containers)이며 합격선은 실측으로 확정한다. 이 축①(격리 경계 등급)은 dp2(일회용 컨테이너 실행 구조) 위에 얹는 결정으로, 채택 등급이 "샌드박스 내부 = 자동 승인" 원리(축② 승인 배정)의 전제를 공급한다.
