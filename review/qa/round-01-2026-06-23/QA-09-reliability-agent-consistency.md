# Review: QA-09 Reliability — Agent 결과 일관성

> source: `context/qa/QA-09-reliability-agent-consistency.md` + `QAS-09-reliability-agent-consistency.md`
> verdict: **Sound △ / KPI △** — 일관성과 정확성을 혼동하고, 결정성 목표 자체를 재고해야 함 · severity **Med**
> lenses: (1) Agentic Workflow 전문가 · (2) 20년차 수석 아키텍트 · (3) 대규모 Workflow Runner 인프라 아키텍트

## 원문 요약
- **정의**: 동일 입력에 일관된 판단.
- **KPI**: 추론 재현 성공률 ≥ 80%
- **QAS**: 자극=동일 작업 재요청 / 응답=일관된 판단 / 설계연결=DP-0005 공유 캐시.

## 렌즈 1 — Agentic Workflow 전문가 관점

**LLM에서 완전한 결정성은 불가능/고비용이며, 추구 대상이 잘못 설정됐다.** 같은 입력·temperature=0이어도 배치·하드웨어 차이로 출력이 흔들린다. 옳은 프레이밍은 “같은 출력”이 아니라 **허용 오차 내 일관된 (유효) 결정**이다.
- **DP-0005 공유 캐시로 동일 입력을 캐시하면 재현율은 자명하게 ~100%가 되지만 이는 “치트”다.** 저장된 답을 되돌려줄 뿐, 일관성을 입증하지 못하고 **유사(semantically-equivalent) 입력**의 흔들림은 전혀 못 잡는다. KPI가 캐시로 부풀려지지 않게 **순수 추론 기준(캐시 제외) 재현율**을 따로 측정해야 한다.
- 결정 안정성을 높이는 정공법: temperature=0, fixed seed(지원 시), structured output, self-consistency voting. 캐시는 비용 절감책이지 일관성 입증이 아니다.
- 진짜 관심사 = **의미적으로 동일한 입력에서 결정이 흔들리지 않는가**.

## 렌즈 2 — 20년차 수석 아키텍트 관점 (QA 완성도)

- **일관성 ≠ 정확성(핵심 결함)**: 일관되게 **틀릴** 수도 있다. 정확성 앵커 없는 일관성은 약한 QA다. 80% 재현율이 “1/5는 갈린다”인데, 갈린 결과가 다 유효하면 괜찮고 일부가 오답이면 심각 — KPI가 이를 구분 못 한다.
- **“성공”의 정의 부재**: 동일 결정? 동일 **유효** 결과? 정의해야 측정 가능.
- 권고: 결정성보다 **유효-결정률 + 재실행 분산**으로 재프레이밍하고, **정확성(C5 NQA-B)과 짝지어야** 신뢰가 성립.

## 렌즈 3 — 대규모 Workflow Runner 인프라 아키텍트 관점

**durable 엔진은 워크플로우 골격엔 결정성을 강제하지만, LLM 비결정은 별개다.**
- **결정론적 워크플로우 코드**: replay 기반 엔진은 오케스트레이션 로직의 결정성을 요구한다(같은 이벤트 → 같은 다음 단계). 즉 **제어 흐름은 재현 가능**하나, activity 안의 LLM 호출 결과는 그렇지 않다 — QA-09가 노리는 건 후자다.
- **activity memoization = DP-0005 캐시**: runner의 결과 메모이제이션은 동일 입력 재실행 시 캐시 반환 — 정당한 멱등성 기능이지만, 렌즈1·2 지적대로 **모델 일관성을 입증하지 못한다**. 측정 시 memoization 우회 모드 필요.
- **버전 핀닝**: model/prompt/tool 버전을 워크플로우에 고정해 재현 조건을 통제.
- **runner 측 KPI**: 버전 핀닝 커버리지, memoization 적용/우회 범위 명시.

## Stage 2 권고

- **재프레이밍**: “동일/**유사** 입력에서 **유효 결정**의 안정성”.
  - KPI① **순수 추론 재현율(캐시 제외) ≥ ◯**
  - KPI② **유효-결정률(재실행 N회 중 정책상 유효한 결정 비율) ≥ ◯**
  - KPI③ 재실행 결과 분산 ≤ ◯
- **정확성 앵커 연결**: C5 NQA-B(Correctness)와 짝. 일관 + 정확이 함께여야 자율성 신뢰.
- **캐시 주의**: DP-0005 캐시가 KPI를 부풀리지 않도록 측정 시 캐시 우회 모드 명시.
- **importance 재검토**: 현재 L이나, 자율성 신뢰의 토대라 NQA-B와 묶이면 상향 여지.
